# 教師原教材歸屬接回（驗收環境）

使用者已確認原作者帳號。只以明確的作者確認核准對應教材，不把 Google email 相同視為教材擁有權，也不授予全站管理員。

`studio.source_grants` 為逐帳號／逐來源課程的可撤銷核准；來源副本保留原作者與來源摘要。老師只看核准的來源、圖片、影音與引用的套件子檔，未連結素材仍由管理員整理。每次請求重讀核准，撤銷後立即拒絕來源媒體。學生仍透過班級提供的固定版本及原有權限取得素材。

此次保留原始來源與歷史資料表，不重新指派學生或聊天身分。核准與素材搬入只限獨立 PostgreSQL 驗收環境，不修改 Firebase 或正式站。公開程式庫不包含私人教材、作者清單或登入憑證。

驗證：來源範圍、非本人拒絕、縮圖、來源副本儲存、偽造素材參照拒絕、套件子檔與即時撤銷已加入 `studio/test.mjs`。完整畫面驗收結果待實際操作後補記，不能以 API 測試替代。
