# webAVR 學習工作室 v0.7.3

國小教師建立地圖與 360 教材，學生透過縮圖選課、辨識點與功能圖標探索、作答，教師查看班級學習概況及課後小結。

目前是本機整合版，使用 React、Node.js、Pannellum 與磁碟持久保存的 PGlite。尚未切換正式 server 或原生 PostgreSQL。測試帳號不代表已完成真實師生帳號搬遷。

## 啟動

需要 Node.js 22 以上。在本目錄執行 `npm ci`、`npm run build`、`npm run demo`，開啟 http://127.0.0.1:3000/ 。只監聽本機；正式部署前須移除固定測試登入、設定 HTTPS、正式資料庫、郵件服務及備份。

已有服務時不要再啟動第二個程序開啟同一份 `private-studio/database/`。正常關閉服務後，必須一起備份整個 `private-studio/`；其中包含資料庫、來源目錄、原媒體與上傳素材。重新啟動會保留資料。

AI 功能須在伺服器環境設定 `OPENAI_API_KEY`；不要把金鑰放入前端、聊天或版本控制。未設定時會明確顯示不可用，不會自動呼叫 AI。正式使用仍須檢查教材權利與資料使用範圍。

## 主要入口

- `/studio`：老師教材、縮圖總覽、地圖／場景／活動編輯、儲存與提供班級。
- `/learn`：學生滑動縮圖選課、360 探索、作答、課程助教。
- `/class-learning`：老師查看探索與作答紀錄、班級小結及複習重點。
- `/`：帳號、班級、歷史封存與工作室。

助教支援老師教學規則、繁中／英文及語音輸入與本機朗讀；語音權限與裝置支援仍依瀏覽器而異。老師產圖先私人預覽、確認加入場景後再儲存與提供班級。

## 驗證與限制

`npm test` 執行核心、教材驗證、儲存復原、影音、學習紀錄、小結、助教及圖片功能測試；`npm run test:studio` 檢查舊教材與編輯，需本機私人來源目錄；`npm run test:canvas` 檢查畫布座標。

v0.7.1 以隔離合成班級完成 33 項 HTTP 資料流程驗收，包含圖片上傳、教材版本、斷線重送、探索作答與課後小結。這不等同完整瀏覽器或實體平板驗收。小結目前按班級／教材版本累計，尚未分隔每次上課場次。

真實帳號與全量歷史資料搬遷、原生 PostgreSQL、SMTP、正式部署、全媒體對帳與實體裝置驗收仍待完成。舊文件保留於 `docs/history/`，其中功能缺項描述是當時狀態。詳細教材流程見 [教材工作區說明](studio/README.md)。
