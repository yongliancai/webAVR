# 舊參考答案核准套用（驗收環境）

維護者以私人核准清單呼叫 `deploy/apply-reviewed-answers.mjs` 的 `applyReviewedAnswers`。預設 dryRun，不提供公開HTTP入口。清單包含既有老師、證據來源、草稿與題目ID、預期修訂、已確認題目／選項及答案；不得把實際題目與答案、私人核准清單或資料庫憑證提交GitHub。

套用前須同時通過本人草稿、有效teacher角色、逐來源教材授權、題目／選項比對與隔離保存的原答案核對。僅新增 `payload.grading` 及草稿新修訂，保留原內容、縮圖、辨識點及功能圖標。多份草稿使用單一交易，衝突時全部回復；相同核准重跑不重複增加修訂。

不更新class_lessons、lesson_versions、learning_events或原始教材。判分驗收須在另一個明確合成班級提供新修訂，已提供舊班級的版本不自動升級。已保存未判分答案不追溯改判。

驗證包含dry run不寫入、他人草稿拒絕、錯誤舊答案與變更選項拒絕、重複題目拒絕、跨草稿失敗回復、舊修訂與已提交答案保留、重跑及撤銷授權。
