# AI 助教與圖片生成（v0.9.1）

AI功能已先在獨立驗收環境測試，通過後更新到新版網站。沿用既有金鑰；金鑰不會出現在瀏覽器、對話回覆或這個公開儲存庫。

## 老師如何使用

### 課程助教

1. 開啟教材的「助教設定」。
2. 勾選讓學生使用助教，設定名稱、教學方式及教學規則。
3. 儲存草稿，再更新「提供給班級」的版本。

學生可選繁體中文或英文及回答長度，使用語音輸入或裝置朗讀。助教遵循老師設定引導觀察；回答可能有誤，仍需老師確認。

### 教學圖片

1. 在「圖片生成」選擇參考教材並描述想呈現的內容。
2. 產生後查看預覽，確認圖片適合教材，再勾選確認。
3. 加入場景知識圖標或新增平面教學場景。
4. 儲存草稿，再提供給班級，學生才會取得新版本。

生成的是平面教學示意圖；原360場景、辨識點、功能圖標及縮圖保留。圖片及助教設定不會自動套用到舊教材。
