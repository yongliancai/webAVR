# 完整畫面與平板驗收清單

本文件是操作清單，不是整份已通過紀錄。2026-11-25 Chrome 實際操作與下載、多課程驗收結果見 [畫面驗收紀錄](ui-acceptance-20261125.md)。使用者目前沒有平板，實體測試尚未執行；裝置到位後依下方步驟進行。

## 固定驗收教材

使用隔離驗收服務 `studio/serve-acceptance-test.mjs` 的「景觀觀察」，一位老師、兩位學生，兩個 360 場景、一張兩站地圖、知識點、傳送、一題有參考答案與一題未判分觀察題。不得修改或提供原教材。

本機獨立驗收入口為 http://localhost:3998/test/teacher 與 http://localhost:3998/test/student ，會切換本機合成帳號。老師與學生應分開瀏覽器／無痕視窗操作，避免同一瀏覽器共用 cookie。這些路由只存在驗收啟動器。

`localhost` 僅代表目前操作裝置，平板輸入此網址不能連到電腦網站。實體平板需要隔離、受保護且具 HTTPS 的驗收環境；不可把含固定測試帳號與故障注入路由的驗收服務直接公開。正式網站須在驗收完成後再切換。

## 裝置矩陣

| 裝置 | 規格／方式 | 狀態 |
|---|---|---|
| 電腦 Chrome | 一般桌面寬度；滑鼠、鍵盤、縮放 | 核心操作已驗，詳見獨立紀錄；不代表全部故障情境通過 |
| 平板直向模擬 | 768×1024 或裝置實際 CSS 尺寸 | 核心版面已驗；不等同實機 |
| 平板橫向模擬 | 1024×768 或裝置實際 CSS 尺寸 | 核心版面已驗；不等同實機 |
| 實體 iPad Safari 或 Android Chrome | 記錄型號、系統、瀏覽器版本與網路 | 待確認裝置及驗收環境 |

## 老師：編輯並提供

1. 以老師登入，開啟隔離課程。確認縮圖總覽、WA 標誌與課程名稱正確。
2. 更改驗收課程名稱與目標，選取合成圖片上傳；確認進度、取消、重試回饋，取消後不可誤換原圖。
3. 切換地圖及兩個場景縮圖。地圖縮放後標記位置正確，連到預期場景；旋轉平板後位置不偏移。
4. 拖曳 360 看四周、縮放。開設定面板後仍可看到畫布；鍵盤彈出時輸入框與儲存按鈕可到達。
5. 點辨識點，先展開功能圖標，再開知識點、題目及傳送。活動視窗可關閉並回到同一視角。不可把圖標拖曳誤當放置新標記。
6. 修改未儲存時關頁再開，確認復原提示；選復原後仍保留圖片、座標、圖標與題目。
7. 儲存後點「提供給班級」，核對班級及修訂。未儲存修改不能提供。成功後「查看此班級的課後小結」應選中正確教材。
8. 故障注入只在隔離環境執行：提供成功但回應遺失時確認結果；完全離線時顯示待確認並可重查，不連續送出寫入。

## 學生：選課、探索與作答

1. 開啟學生選課頁，確認只有已提供教材。滑動卡片、左右箭頭、鍵盤方向鍵皆可選課；中央卡片突出、側邊淡出，縮圖不被替換成純文字清單。
2. 點開始探索，確認載入提示消失、實際 360 可環視。觸控與雙指縮放不誤觸課程切換；旋轉裝置不出現黑畫面。
3. 點辨識點→功能圖標→知識點，再關閉；點題目選答案並送出。送出狀態、成功與錯誤提示清楚。
4. 用傳送及地圖到第二站，提交未判分題。刷新後進度保留；第二位學生保持未開始。
5. 離線提交，再恢復網路重試：待同步提示消失，同一答案不重複計次。若本機副本無法保存，離開前有明確警告。
6. 老師更新教材版本時，仍開著舊版的學生可讀舊圖並同步舊版答案；重新選課後顯示新版與新版進度。
7. 降低畫質與重試全景可用；故意載入失敗時仍能使用活動清單，不能整頁當掉。

## 老師：課後小結

1. 查看正確班級／教材／版本：兩人中一人完成、一人未開始。
2. 首次有參考答案題答錯，應進複習重點；未設定參考答案題標示待人工檢視，不能算答錯。
3. 點複習項目，應直達對應題目。查看個人每次作答，返回時班級與版本不變。
4. 學生重新答對後，最新統計更新，歷次作答仍保留；下載文字小結不含學生姓名。
5. 切換舊版可回看；讀取失敗不能顯示為全班零紀錄。小結目前為版本累計，不能稱作獨立上課場次。

## 實體平板測試安排（待裝置）

預留 35–45 分鐘。優先 Android 平板 Chrome；若實際提供 iPad，記錄瀏覽器及系統版本，依相同步驟另行驗收。

1. 準備（5分鐘）：記錄型號、系統／瀏覽器版本、螢幕方向與網路。由維護者先提供受保護 HTTPS 驗收入口及合成帳號；目前的 localhost SSH 通道只供電腦使用，不能直接填到平板。不得直接公開含測試捷徑的驗收服務，也不修改正式域名。
2. 老師（10分鐘）：直向／橫向查看縮圖→編輯文字→鍵盤彈出後仍可找到儲存→上傳合成照片、取消、重試→儲存→提供合成班。檢查畫布、面板及地圖標記在旋轉後不偏移。
3. 學生（10分鐘）：切換成學生身分；三門卡片手指左／右滑至少各三次，點按「開始探索」不被滑動攔截。環視與縮放360、辨識點→功能圖標→題目、傳送與地圖，直橫向各完成一次。確認沒有誤選課程、黑畫面或被截掉的關閉按鈕。
4. 中斷復原（5分鐘）：作答後重新整理核對紀錄；切換背景再返回。只在合成資料斷網測試待同步與恢復，重試不能重複計次。
5. 老師小結（5分鐘）：切回老師核對正確版本、複習題與未判分，下載文字小結並在裝置「下載／檔案」中開啟核對中文。取消儲存再重試亦可；網站不能把尚未確認的下載聲稱為已存檔。
6. 選測（5–10分鐘）：需要語音驗收時另確認麥克風權限，實測中英文輸入、停止與朗讀；不把本次 AI 關閉的合成服務當成真實助教通過。

每項填寫「步驟／預期／實際／通過或失敗／截圖」。核心流程無無法操作、資料遺失、選錯教材或整頁崩潰才可結束；任一失敗先記錄再修復複驗。未取得實體裝置前保持「未測」，不安排自動提醒或切換正式站。

## 發布前條件

- 所有核心畫面步驟通過；平板模擬與實體結果分開標示。
- 原教材雜湊／修訂與更新前備份一致；媒體清冊另行對帳。
- 正式帳號、原生 PostgreSQL、寄信、HTTPS、備份還原與回復方案完成，移除固定 demo 登入。
- GitHub 公開庫只提交原始碼，排除私有資料、原教材、學生紀錄與金鑰；`.gitignore` 不是完整洩密檢查的替代品。
- 在 staging 驗證資料與功能，再安排正式切換。本次尚未切換正式 server。
